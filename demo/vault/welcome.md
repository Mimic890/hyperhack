This post is the file `demo/vault/welcome.md`. Change this sentence, save the file and reload the page within ten seconds.

## Try it

- Edit this file. The change appears after the next poll.
- Add a new `.md` file with a `title` and a `date`. It becomes a post.
- Delete a post file. The post goes away.
